# student_report_card
This is a beginner-friendly Python mini project that generates a student report card based on the student's name and marks.
## Featuers
- Take the student's name and marks as the input.
-  Calculates the total marks and average marks.
- Determines the student's grade.
- Generates a student report card.
- Validates marks and displays the error message if they are outside the range of 0-100.
## Purpose 
This project was created to practice basic Python programming concepts, including user input, conditional statements, calculations, and error handling.
## Language used
- Python
